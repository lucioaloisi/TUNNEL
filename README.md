# TUNNEL

Cartella principale del repository GitHub: `TUNNEL`

File: `index.html`, `BUONO.glb`, `CATTIVO.glb`, `SFONDO1.jpg`, `SFONDO2.jpg`

Va servito via HTTPS (GitHub Pages: Settings > Pages > branch main, cartella root).
Il sensore di movimento su iPhone e Android funziona solo in HTTPS.

Comandi: inclina il telefono (posizione neutra = quella al tocco di INIZIA), tocca per sparare.
Desktop: frecce/WASD, spazio, C = ricalibra.
Se una nave appare al contrario: tasto 1 (buona) / 2 (cattiva), oppure `?flipP=1` / `?flipE=1` nell'indirizzo.
